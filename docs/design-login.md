# DouYin Spark Flow 登录页设计规范

## 1. 设计目标

登录页是私有管理后台的认证入口。视觉主题改为“关系的流动，而不是打卡的堆叠”：以原创数码像素波浪作为唯一主视觉，建立高级、安静且持续流动的数字氛围。

页面不再使用等距城市图片、米白/黑色硬分屏、工业大框或密集 HUD。它也不是赛博朋克或游戏大厅：不使用霓虹发光、紫色渐变、玻璃拟态、重型图形技术或高频闪烁。

核心文案：

> 火花因人而亮，不因打卡而生。  
> 别让死板的形式，框住本该自由的友谊。

## 2. 页面结构

```text
┌─────────────────────────────────────────────────────────────┐
│ Brand / color ticks / descriptor                             │  64px
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  不规则数码纹理在完整深黑画布上局部浮现、连接、消退            │
│                                                             │
│  品牌标题与四项能力                       控制台登录          │
│  （波浪密度最高处）                       （由暗场自然留白）  │
│                                                             │
│                                           SYSTEM ONLINE      │
└─────────────────────────────────────────────────────────────┘
```

- 页面使用 `100dvh`；桌面端首屏完成登录，不依赖滚动。
- 顶栏为 64px 半透明深黑品牌栏，允许纹理从后方贯穿。
- 全页为统一深黑画布；纹理贯穿文字和表单区域，只以局部轻暗场和文字暗色阴影保护阅读。
- 登录区无 Card、无独立边框，只通过空间与明度形成层次。

## 3. Layout 与响应式

- Desktop `> 1200px`：主布局 `56fr 44fr`，左侧安全边距 `clamp(38px, 5vw, 88px)`；表单固定上限 420px。
- Compact desktop `768px–1200px`：双栏收敛为 `51fr 49fr`，标题用 `clamp()` 缩小，表单保持 `min(420px, calc(100% - 64px))`。
- Mobile `< 768px`：单栏，顺序为 Brand → 标题/理念/能力 → Login → Status；Hero 最小高 286px，登录区最小高 540px。
- 所有装饰层 `pointer-events: none`；根元素 `overflow-x: clip`。页面可纵向滚动，禁止装饰制造横向滚动。

## 4. 色彩

| Token | Value | 用途 |
| --- | --- | --- |
| `--login-dark` | `#090B0D` | 全页底色与表单暗场 |
| `--login-text-light` | `#F4F4F4` | 标题与主要正文 |
| `--login-muted` | `#8A8D91` | 次级说明与状态 |
| `--login-brand` | `#F43F5E` | 标题第二行、主按钮、少量波峰像素 |
| `--login-cyan` | `#15C7E8` | 极少量在线状态与波浪信号点 |
| `--login-yellow` | `#F5C842` | 极少量过渡与标记 |
| `LoginForm` 输入背景 | `#11151A` | 输入框背景；当前为组件内字面值，不是页面级 CSS 自定义属性 |

中性灰像素是波浪的主体；品牌红只做稀疏信号，不扩展为整屏底色。青色和黄色仅作少量点缀，不使用绿色、紫色或任何光晕。

## 5. Typography

- 中文标题与正文：沿用项目字体栈 `Microsoft YaHei / Noto Sans SC / Segoe UI / sans-serif`。
- 主标题：桌面 `clamp(52px, 4.55vw, 82px)`，`font-weight: 860`，行高 `1.04`，字距 `-0.045em`；第二行使用品牌红。
- 理念副文案：16–20px，颜色 `#C4C7CB`，宽度不超过 620px。
- 登录标题：30–37px，中文为主；`CONTROL PANEL` 可使用 10px 等宽标签以满足控制台语义。
- 等宽字体仅用于状态和少量英文工具信息；不把中文文字像素化。

## 6. Digital pixel field — 最新方向

用户在实际预览后明确否定规则波浪感，以 trae.cn 的不规则浮现纹理为参考；此方向覆盖此前的城市、SVG 和五条潮汐波带方案。

- 单个 Canvas 2D 覆盖全页，包含顶栏后方、登录区周围和底部；不复制参考站的图片或品牌资产。
- 桌面与常规移动端使用固定 `5px` 方形像素、约 `7px` 网格步距；超大画布仅为控制像素总量等比放大，不随机改变单颗像素尺寸。
- 灰阶采用四档中性离散色：`#2C2C2C`、`#353535`、`#505050`、`#6D6D6D`。取消背景中的红/青/黄胡椒点；品牌色只以随机散落的浅粉像素出现，不形成连续色域。
- 连续三维噪声流场以不同空间相位驱动每颗像素；宏观密度、中尺度纹理与细颗粒叠加，任何区域都没有共享的出现、停留或消失周期。
- 两组缓慢变形的噪声坐标产生横向与纵向微小流动；新纹理会在旧纹理仍可见时从内部和边缘穿插生长，不等待一个大形状退场。
- 纹理局部出现、连接和消失；没有整屏同步呼吸、像素漂移、逐帧随机闪烁或永久均匀底噪。
- 黑色空隙由每颗像素的局部密度阈值自然形成，不是团簇或固定遮罩；整个页面都有生成纹理的机会，不要求每个角落每时刻都亮起。
- 灰色是背景纹理主体；红/青/黄只保留在品牌、按钮和状态组件中，中文字体、文案和认证交互不变。
- 认证区只保留最高 38% 的柔和局部暗场，顶栏为半透明；输入框保持实色，不让装饰侵入控件。
- 桌面上限 60fps、手机 30fps；DPR 上限 1.5，常规采样网格为 7px，超大画面限制总像素量。
- 页面隐藏时暂停，恢复后接续时间；减少动态模式只绘制静态帧。卸载清理 RAF、ResizeObserver 和监听器。
- 验收使用真实浏览器截图、跨时间像素变化及原生 MediaRecorder 背景录制；不是参考网站源代码的精确复刻。

## 7. Components

- `LoginPage`：保持 Pinia `auth.login()`、空值校验、loading、错误、redirect 和路由逻辑；仅负责编排页面级视觉层。
- `BrandHeader`：火花图标、中英文品牌名、三枚色块与私有管理标记。
- `HeroSection`：核心标题、理念副文案、四项能力与少量底部信号点。
- `DigitalWave`：原创 Canvas 2D 数码像素流场；不依赖任何外部视觉资产。
- `FeatureList`：展示定时续火花、多账号管理、登录状态同步、异常目标监控；采用点状标记和文本，不使用硬边 Chip。
- `LoginForm`：保留用户名、密码显隐、Enter 提交、错误反馈、loading 与安全说明。
- `SystemStatus`：有限状态序列 `CONNECTING… → SYNCING… → SYSTEM ONLINE`。

## 8. Border 与控件

- 移除主体的大型框线、左右分栏线与功能 Chip 外框。
- 输入框保留必要的 1px 内描边；52px 高，focus 使用 `rgba(244,63,94,.7)`，不发光。
- 主按钮为 52px 品牌红，hover 只提升亮度，active 只产生 1px 像素位移。
- 安全说明和系统状态不再用横线包围，依靠留白与低对比文字分层。

## 9. Motion 与可访问性

- 品牌栏 450ms、Hero 560ms、表单 560ms 入场，均使用 `cubic-bezier(.22,1,.36,1)`。
- 波浪是页面唯一持续环境动效；其它状态不做循环晃动。
- `prefers-reduced-motion: reduce` 时，Canvas 停止持续重绘，BrandHeader、Hero 和表单入场动画停止；系统状态直接显示 `SYSTEM ONLINE`。
- 输入、按钮、错误反馈与安全说明保持原有语义；错误使用 `aria-live="polite"`。

## 10. 验收标准

- 页面不再出现“让每个好友都不再断火花”、像素城市或其资源引用。
- 标题准确为“火花因人而亮，不因打卡而生。”，副文案准确为“别让死板的形式，框住本该自由的友谊。”。
- 背景为连续的数码像素波浪，不使用任何整张背景图。
- 表单无硬质大框，认证 API、校验、密码显隐、Enter、loading、错误和 redirect 保持不变。
- 1440×900、1920×1080、390×844 无横向滚动或内容遮挡。
- 减少动态模式可用，生产构建通过。
